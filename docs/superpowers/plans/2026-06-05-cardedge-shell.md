# CardEdge Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold the full CardEdge frontend shell — landing page, persistent app navigation, dashboard with KPI cards and empty feeds, five pillar pages, and settings — with adaptive dark/light theming and no backend or auth.

**Architecture:** Next.js App Router with a `(app)` route group that shares a persistent top-nav layout across all authenticated pages. The landing page lives outside the route group with its own nav. Theme is managed by `next-themes` with Tailwind's `class` dark mode strategy. Components are small and single-purpose; pages are thin wrappers that compose them.

**Tech Stack:** Next.js 14+ (App Router), TypeScript, Tailwind CSS, shadcn/ui (Button, Card, Avatar, Separator), next-themes, lucide-react

- [ ] **Step 3: Create the ThemeToggle component**

```tsx
'use client'

import { useTheme } from 'next-themes'
import { Moon, Sun } from 'lucide-react'
import { Button } from '@/components/ui/button'

export function ThemeToggle() {
  const { theme, setTheme } = useTheme()

  return (
    <Button
      variant="ghost"
      size="icon"
      onClick={() => setTheme(theme === 'dark' ? 'light' : 'dark')}
    >
      <Sun className="h-4 w-4 rotate-0 scale-100 transition-all dark:-rotate-90 dark:scale-0" />
      <Moon className="absolute h-4 w-4 rotate-90 scale-0 transition-all dark:rotate-0 dark:scale-100" />
      <span className="sr-only">Toggle theme</span>
    </Button>
  )
}
```
